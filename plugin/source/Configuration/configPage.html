Music Discovery

Inject MusicBrainz search results into Jellyfin's music library. Album requests route to Lidarr; track requests stream on demand from slskd.

Library

Absolute path to your Jellyfin music library root. Discovery downloads are written to a subfolder of this path.

Search source

Deezer has no auth, no User-Agent, and feels instant. MusicBrainz is rate-limited but has better coverage of niche/obscure releases.

MusicBrainz (used at request time + as fallback)

MB requires a descriptive UA with contact info, e.g. "JellyMusicDiscovery/0.1 ( your.email@example.com )". Only used if you pick MusicBrainz or Both above, or for canonical-id lookups when requesting albums by MBID.

Lidarr (album requests)

YT Music stream server (instant playback)

Companion service that resolves track names to YouTube Music audio URLs via yt-dlp. When set, clicking play on a discovery track redirects to this server which 302s to a direct CDN audio URL — instant playback. Leave blank to fall back to slskd (slow).
